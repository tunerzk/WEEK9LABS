# WEEK9LABS – GCP Load Balancer Lab  
This project demonstrates deploying a complete Google Cloud Platform (GCP) HTTP Load Balancer using both ClickOps (manual console steps) and Terraform (Infrastructure as Code).

The goal of this lab is to understand:
- How to build cloud infrastructure manually in the GCP Console  
- How to automate the same infrastructure using Terraform  
- The differences, benefits, and tradeoffs between ClickOps and IaC
